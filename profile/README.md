## Hi there 👋


Dicoogle is an extensible, platform-independent and open-source PACS archive software that replaces the traditional centralized database with a more agile indexing and retrieval mechanism. It was designed to support automatic extraction, indexing and storage of all meta-data detected in medical images, including private DICOM attribute tags, without re-engineering or reconfiguration requirements.

🙋‍♀️ This is the github organization for Dicoogle


### 👩‍💻 Useful resources

- The official Dicoogle core lives in <https://github.com/dicoogle/dicoogle>.
- The open plugins with baseline storage and indexing providers are in <https://github.com/dicoogle/dicoogle-plugins>.
- A new revision of the project is under development in <https://github.com/dicoogle/dicoogle-next>.


Our official website is at https://www.dicoogle.com. A few essential plugins for Dicoogle are available to download there, as well as a built jar of the Dicoogle platform. To learn how to use Dicoogle, please see our [Learning Pack](https://dicoogle.github.io/dicoogle-learning-pack). To build the core platform yourself, please see the section on [Building Dicoogle](#building-dicoogle) below. The learning pack also has a page on [Building Dicoogle](https://dicoogle.github.io/dicoogle-learning-pack/docs/building/).
